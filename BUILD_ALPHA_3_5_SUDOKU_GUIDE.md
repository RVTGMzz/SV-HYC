# v0.0.7-alpha.3.5 — Sudoku Beginner Guide

The beginner guide is an overlay on every Daily, Stage, and Endless Practice board. It never mutates the puzzle or progression state.

## Access

- Mouse: click `? Hướng dẫn / ? How to Play`.
- Keyboard: `H` or `F1`.
- Controller: Back/View.

## Contents

- Fill every empty cell with 1–9.
- No repeated number in a row, column, or 3×3 box.
- A visual 3×3 elimination example whose missing center is 5.
- Fixed-clue/player-entry color legend.
- Short entry, erase, and check controls.
